# Caffeine

A macOS menu bar app that prevents your screen from sleeping.

## Installation

1. Clone the repo
2. Run `bash bundle.sh` to build
3. Open `Caffeine.app`

## Usage

Click the cup icon in your menu bar:

- **Keep Awake For** — pick a preset duration (30 min, 1 hr, etc.) or choose **Custom…** to enter any number of minutes
- **Pause / Resume** — temporarily suspend without losing the remaining time
- **Deactivate** — stop immediately
- **Quit** — stop and exit (`⌘Q`)

The menu bar icon shows a filled cup and a countdown while active.
